# Wedonomics

A mobile-first wedding budget planner. Plan events, categories, activities and installment payments, and track budget versus paid across the whole wedding.

**Stack:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui, React Router, Recharts, Supabase.

Built in staged steps, one branch and PR per step. Setup instructions will be added as the project is scaffolded.
